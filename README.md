# Word check

A free, offline word checker for iPhone and iPad running iOS 26 or later.

Choose NASPA (NWL 2023) or Collins (CSW 2024), enter a word, and tap **Check**. A clear verdict appears immediately. The word stays selected so you can type the next one straight away. Your dictionary choice is remembered.

No accounts, ads, subscriptions, or in-app purchases. Word checks work without an internet connection.

## Support

[Ask a question or report a problem](https://github.com/rau/word-check-support/issues/new).

For a word-list question, include the word and the selected dictionary edition. For an app problem, include your iPhone or iPad model, iOS version, and what happened. GitHub issues are public; please do not include personal or sensitive information.

## Dictionary information

NASPA uses the NASPA Word List 2023 edition. Collins uses Collins Scrabble Words 2024. These editions can differ, so agree on a dictionary before playing.
